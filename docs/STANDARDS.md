# معيار ثيمات خالد الدائم · Khaled's Permanent Theme Standard
> يطبّق تلقائياً على كل ثيم جديد بدون ما يعيده خالد. المرجع الحي: Taqni (/workspace/techno-theme, playkhaled20/techno-theme).

## 0. قواعد لا تُكسر
- لا رفع/نشر/Partners/Twilight CI حتى يقول خالد «كله مضبوط». commits محلية فقط، بدون push.
- بهاء (fooz1980k-sudo/aneeq-theme) لا يُلمس: master/review/publish/stash. لا force push أبداً. تحقّق بعد كل جلسة: HEAD + status + stash.
- مكتبة اضافاتنا (playkhaled20/idhafatina) للقراءة/النسخ فقط؛ لا تتعدل من داخل ثيم.
- لا دفع أموال، لا طلب كلمات مرور.

## 1. الأساس
- قاعدة Raed (MIT) + معايير سلة Twilight: twilight.json صالح، components بمفاتيح ثابتة (uuid5)، عناصر سلة الأصلية (salla-products-list, cart, options) تبقى أصلية.
- RTL أولاً، عربي + إنجليزي. ثيم عام لأي متجر من فئته.
- الاسم: كلمة واحدة عربي + كلمة واحدة إنجليزي بأسلوب سلة (رائد/Raed). تحقّق قبل الاعتماد: GitHub search API + بحث ويب + متجر ثيمات سلة (البحث من لوحة سلة هو التأكيد النهائي). الاسم والوصف متطابقين.
- zip الثيم < 1MB (قِس بعد build: ملفات git + public).

## 2. التصميم المعتمد
- إنفوجرافيك فاخر داكن افتراضي (body.tech-ig): حلقات conic، أشرطة متحركة، ألواح زجاجية، ذهبي + لون أساسي. CSS خالص بدون أصول خارجية، يحترم reduced-motion.
- أيقونات SVG فقط (لا إيموجي). بار أزرار ذكي سفلي زجاجي للإضافات.
- 12 لون فاخر يختاره التاجر من إعدادات الثيم (dropdown) + خيار «لون المتجر من سلة» افتراضي. اللون يغيّر --color-primary و--ig-acc و--ig-gold.

## 3. أنظمة ذكية بدل الأرقام والنجوم
- نبض المخزون: مؤشر دائري + حكم لفظي (متوفر بثقة/توفر جيد/الكمية تقل/آخر القطع/نفدت·نبّهني) + «رائج» من المبيعات. لا تُعرض الكمية الخام.
- مؤشر رضا العملاء: حلقة % + حكم (استثنائي/عالٍ/جيد/متباينة) + أشرطة ثقة (عالية/متوسطة/أولية) بدل النجوم والعدد.
- مؤشر ثقة المتجر: حلقات بنسب + أحكام. كله من بيانات سلة الحقيقية فقط، ويرجع الأصلي لو انطفأ النمط.

## 4. أقسام الفئة (لكل متجر من الفئة)
- قسم فئات يغطي كل فئات سلة للقطاع (للتقني 24 فئة) بأيقونات، يربط بتصنيف سلة أو يرجع للبحث.
- أقسام إنفوجرافيك: hero بأرقام، منتجات بالأرقام، مقارنة، بطاقات رقمية، مختبر أداء، خطوات طلب/ضمان، مؤشر الثقة. كلها قابلة للتعديل من لوحة سلة بقيم افتراضية واقعية.

## 5. إضافاتنا
- تُركّب كل إضافات اضافاتنا المناسبة للفئة بشكل فاخر (بار SVG + لوح زجاجي) وتُستبعد غير المناسبة مع ذكر السبب.
- كل إضافة تاخذ اسم يناسب منتجات الفئة (مثال التقني: المستشار الذكي، بحث صوتي، هدية تقنية، اختر جهازك، صمّم سيتبك، فحص صورة المنتج، اسمع المواصفات، ألوان الجهاز، على مكتبك، نسخة بكسل، كمّل الطقم).
- كل إضافة تستخدم منتجات وصور المتجر نفسه فقط (salla.product.fetch / صفحة المنتج). ممنوع صور stock أو نصوص من فئة ثانية (أزياء).
- كل إضافة لها مفتاح تشغيل/إيقاف في الإعدادات + افتراضي حسب نوع المتجر.

## 6. المعاينة ونوع المتجر
- كشف ذكي تلقائي للنوع من القوائم + أسماء المنتجات والتصنيفات، مع override من إعداد «نوع المتجر».
- بار معاينة سفلي بأسلوب بهاء (يظهر فقط على demo/preview/salla.design أو ?tech_preview=1): يختار النوع ويعرضه مباشرة، مع عدد منتجات المتجر لكل نوع، والأنواع الفاضية معطّلة.
- كل معاينة نوع = منتجات وصور المتجر نفسه المطابقة للنوع (فلترة البطاقات)، ما فيه صور placeholder. لو ما فيه تطابق يعرض كل منتجات المتجر.

## 7. أخطاء بهاء الممنوع تكرارها
فشل CI/نشر صامت · الكتابة فوق twilight.json من البوابة أو وصف خطأ · فوضى أنواع المتجر · صيانة الديمو تحجب المعاينة · صور منتج خطأ أو نفس الصورة لكل لون · مربعات الألوان غير مربعة · zip > 1MB · force push / stash · نشر بدون موافقة · تعارض الاسم والوصف · نقل الريبو يكسر CI.

## 8. التسليم
- لقطات محلية في /workspace/<theme>-shots/ + تقرير بالمسارات وما تغيّر + checklist البنود أعلاه + إثبات أن بهاء ما انلمس.

## 9. صور الأقسام
- كل قسم فيه شريط صور فاخر من 6 إلى 12 صورة (partial: tech-gallery.twig + gallery.js + حقل collection «gallery» لكل component).
- صور التاجر المرفوعة أولاً؛ إذا فاضية تمتلئ تلقائياً بصور منتجات المتجر نفسه المطابقة لموضوع القسم (كلمات مفتاحية)، ولا تتكرر بين الأقسام قدر الإمكان.
- ممنوع تضمين صور داخل الثيم (عشان zip < 1MB) وممنوع صور stock.
